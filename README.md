# VictorinaTop 🎯

**VictorinaTop** — это мобильное приложение для создания и прохождения викторин. Пользователи могут составлять собственные наборы вопросов, публиковать их для других и соревноваться в знаниях, проходя викторины от участников сообщества. Приложение работает на платформах Android и iOS и взаимодействует с собственным серверным бэкендом.

---

## 📱 Для пользователей

### Что умеет приложение

VictorinaTop позволяет каждому пользователю стать как участником, так и автором викторин. После регистрации вы попадаете в общий каталог, где отображаются викторины других пользователей — их можно фильтровать, выбирать по интересующей теме и сразу же проходить.

Если вы хотите создать собственную викторину, достаточно нажать кнопку создания, ввести название и добавить вопросы с вариантами ответов. Готовую викторину можно опубликовать, после чего она станет доступна всем остальным пользователям. После прохождения отображается результат — количество правильных ответов и итоговый балл.

### Как начать пользоваться

Установите приложение на своё устройство. После запуска вам будет предложено создать аккаунт или войти в существующий. Регистрация занимает меньше минуты: достаточно указать имя пользователя и пароль. После входа вы сразу попадёте в главный экран с каталогом викторин, где можно либо выбрать чужую викторину для прохождения, либо приступить к созданию собственной через соответствующий раздел.

## 🛠️ Для разработчиков

### Технологический стек

Мобильная часть приложения написана на **.NET MAUI** — кроссплатформенном фреймворке от Microsoft, который позволяет собирать единое приложение сразу под Android и iOS из одной кодовой базы. Серверная часть реализована на **ASP.NET Core** и предоставляет REST API, с которым общается мобильный клиент. В качестве базы данных используется **SQLite** через официальную библиотеку `Microsoft.Data.Sqlite` — лёгкое встраиваемое решение, не требующее отдельной установки СУБД.

### Структура репозитория

Репозиторий состоит из двух основных проектов. `VictorinaTop.Mobile` содержит весь код мобильного приложения: экраны, навигацию, логику взаимодействия с API и отображение данных пользователю. `VictorinaTop.Server` содержит серверную часть: контроллеры, бизнес-логику, работу с базой данных и конфигурацию приложения.

```
VictorinaTop/
├── VictorinaTop.Mobile/   # Мобильное приложение (.NET MAUI)
└── VictorinaTop.Server/   # Серверная часть (ASP.NET Core)
```

### Требования к окружению

Для локальной разработки вам понадобится **.NET 8 SDK** или выше, который можно скачать с официального сайта Microsoft. Для работы с мобильным проектом рекомендуется использовать **Visual Studio 2022** с установленной рабочей нагрузкой **.NET Multi-platform App UI development** — она включает все необходимые инструменты, в том числе Android SDK и эмуляторы. Если вы хотите запустить приложение на Android-устройстве или эмуляторе, убедитесь, что Android SDK установлен и настроен корректно.

### Установка и запуск

Начните с клонирования репозитория на ваш компьютер:

```bash
git clone https://github.com/ZhirnovArtem/VictorinaTop.git
cd VictorinaTop
```

**Запуск сервера.** Перейдите в папку серверного проекта, восстановите зависимости и запустите приложение:

```bash
cd VictorinaTop.Server
dotnet restore
dotnet run
```

После запуска сервер будет доступен по адресу `https://localhost:7000` (HTTPS) или `http://localhost:5000` (HTTP). Убедитесь, что сервер успешно стартовал, прежде чем запускать мобильное приложение.

**Запуск мобильного приложения.** Проще всего открыть решение в Visual Studio 2022, выбрать `VictorinaTop.Mobile` как стартовый проект и нажать запуск — среда сама предложит выбрать подключённое устройство или эмулятор. Альтернативно можно собрать и запустить через командную строку:

```bash
cd VictorinaTop.Mobile
dotnet restore
dotnet build -t:Run -f net8.0-android
```

**Настройка адреса сервера.** В проекте `VictorinaTop.Mobile` необходимо указать адрес вашего сервера. Найдите файл с константами (например, `Constants.cs`) и укажите нужный URL:

```csharp
public const string BaseUrl = "https://localhost:7000";
```

Если вы запускаете сервер локально и тестируете на Android-эмуляторе, используйте адрес `http://10.0.2.2:5000` вместо `localhost` — эмулятор обращается к хост-машине именно через этот IP.

### База данных

Проект использует SQLite через библиотеку `Microsoft.Data.Sqlite`. База данных представляет собой обычный файл и создаётся автоматически при первом запуске сервера — никаких дополнительных настроек или установки отдельной СУБД не требуется. Файл базы данных по умолчанию сохраняется в директории сервера.
